# Contributing

Thanks for your interest! This is a small prototype, so the process is light.

1. Fork the repo and create a branch: `git checkout -b feature/my-change`
2. Set up locally (see the README).
3. Make your change and add or update tests in `tests/`.
4. Run `pytest -q` and make sure it passes.
5. Open a pull request describing what and why.

## Guidelines

- Keep PRs focused and small.
- Follow PEP 8 for Python; keep frontend code dependency-light.
- Update the README or `docs/ARCHITECTURE.md` if behavior changes.
- Be kind and constructive in reviews.

## Reporting Bugs

Open an issue with steps to reproduce, expected vs. actual behavior, and your OS/Python version.
